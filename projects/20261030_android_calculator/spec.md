# Android Calculator Specification

## Goal

Provide a simple Android calculator for personal use.

## Functional Requirements

- Enter numbers and decimal points using on-screen buttons
- Calculate addition, subtraction, multiplication, and division
- Display entered values and calculation results
- Provide buttons to clear input and delete the last entered character
- Display a clear error message for division by zero

## Scope

- Support calculations with two numbers and one operator at a time
- Keep the interface simple and usable on a phone
- Exclude continuous expressions, parentheses, and calculation history

## Compatibility and Delivery

- Support Android 10 (API 29) and later by default
- Provide an installation package for the user to test on the vivo X300
- Record the user's device test feedback

## Acceptance Criteria

- The app installs and opens on a supported Android device
- Addition, subtraction, multiplication, and division produce correct results
- Decimal input, clearing, deletion, and division-by-zero handling work
- The user can complete the core calculations on the vivo X300
