# intent.md — 20261013_local_RAG

## 意图

在本地实现一个简单但完整的 RAG（检索增强生成）问答 Agent，主题为「汉武帝相关知识」，作为 my_practice 中的独立实践项目。

## 目标

1. **本地知识库**：从互联网收集汉武帝相关的真实内容，覆盖 5 种常见文件类型（PDF / DOCX / TXT / MD / HTML），每种至少 3 份，共 ≥15 份文件。
   - 获取方式：优先下载互联网上现成文件；对难以直接下载的类型，抓取权威网页内容（维基百科、百度百科、史料原文如《史记·孝武本纪》等）后保存为对应格式。
2. **本地 RAG 管线**：文件解析 → 分块 → 本地向量化 → 本地向量库 → 相似度检索，全部在本地完成，不依赖云端存储。
3. **问答 Agent**：Gradio Web 界面，用户提问 → 检索 top-k 相关片段 → DeepSeek 生成答案，答案附带来源文件引用。

## 非目标

- 不做 OCR、表格深度解析等复杂数据处理
- 不做多用户、鉴权、云端部署
- 不追求生产级性能，优先能跑通、可演示

## 已确认的关键决策

| 决策项 | 选择 |
|---|---|
| LLM | DeepSeek API（deepseek-chat） |
| Embedding | 本地 BAAI/bge-small-zh-v1.5（sentence-transformers，约 100MB，离线运行） |
| 向量库 | Chroma（本地磁盘持久化） |
| 文件类型 | PDF、DOCX、TXT、MD、HTML（各 ≥3 份） |
| 交互界面 | Gradio Web |

## 成功标准

- 知识库包含 ≥15 份文件，5 种类型齐全，内容真实、主题相关
- 针对汉武帝问题（如「推恩令的内容」「卫青的战功」「罢黜百家独尊儒术」），Agent 能基于检索内容给出带引用的正确回答
- 对知识库中不存在的问题，Agent 能明确说明知识库中无相关内容，不编造答案

## 约束

- Windows 环境，Python 3.10+
- 需要环境变量 `DEEPSEEK_API_KEY`
- 遵循 my_practice 原则：独立实现、优先跑通、代码保持精简
